# tpaxepklick

Кликер с персонажами. +130 🥛 за клик. Прогресс сохраняется автоматически.

## Как получить APK

1. Зайди во вкладку **Actions** этого репозитория.
2. Открой последний успешный запуск **Build APK**.
3. Внизу страницы — блок **Artifacts** → скачай **tpaxepklick-apk**.
4. Внутри ZIP лежит `tpaxepklick.apk`.
5. Скинь APK на телефон → установи (разреши «Неизвестные источники»).

## Локальная веб-версия

Открой `www/index.html` в браузере.
